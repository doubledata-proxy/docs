This quickstart lists the active Static ISP subscriptions available to your organization.

## Before you begin

You need an active DoubleData organization, an active Static ISP subscription, and your organization's API key. An organization administrator creates the key in the dashboard.

<Steps>
  <Step title="Store your API key">
    Keep the key in an environment variable so it does not appear directly in commands or source files.

    ```bash
    export DOUBLEDATA_API_KEY="your_api_key"
    ```
  </Step>

  <Step title="List active subscriptions">
    Send the key in the `Authorization` header.

    ```bash
    curl --request GET \
      --url https://app.proxy.doubledata.com/api/v1/isp/subscriptions \
      --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}"
    ```
  </Step>

  <Step title="Choose a subscription">
    Save an `id` from the response for subscription-specific requests.

    ```json
    {
      "subscriptions": [
        {
          "id": "25974f58-6a7a-4b0d-8dd7-a89133f50762",
          "tier": "dedicated",
          "countries": [{ "country": "US", "quantity": 2 }],
          "status": "active",
          "proxy_count": 2,
          "current_period_start": "2026-08-01T00:00:00Z",
          "current_period_end": "2026-09-01T00:00:00Z",
          "rotations_total": 20,
          "rotations_remaining": 14,
          "rotations_reset_at": "2026-09-01T00:00:00Z",
          "rotation_in_progress": false,
          "ip_authorization": null
        }
      ]
    }
    ```
  </Step>
</Steps>

`rotations_remaining` counts individual IP replacements, not requests. A successful five-IP rotation consumes five rotation units.
