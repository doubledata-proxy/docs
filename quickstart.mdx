---
title: "Quickstart"
description: "Authenticate and read usage for your proxy credentials."
---

Make your first read-only API request with your organization API key. You can use the same key across proxy products.

<Steps>
  <Step title="Get your API key">
    An organization administrator creates the key in the dashboard. Store it in an environment variable:

    ```bash
    export DOUBLEDATA_API_KEY="your_api_key"
    ```
  </Step>
  <Step title="Read proxy usage">
    This returns workspace totals and per-credential usage for the current UTC month.

    ```bash
    curl --request GET \
      --url https://app.proxy.doubledata.com/api/v1/usage \
      --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}"
    ```
  </Step>
  <Step title="Choose your product">
    Use [Residential](/api-reference/residential), [Datacenter](/api-reference/datacenter), or [Mobile](/api-reference/mobile) for gateway connection parameters. Use [ISP](/api-reference/isp) for Static ISP purchasing and subscription management.
  </Step>
</Steps>

The usage response reports bandwidth in bytes, request counts, and wallet usage charges in USD cents. Static subscriptions use separate subscription records. [Usage reference](/api-reference/usage).

To send traffic through a proxy, use your proxy username and password with a gateway or assigned Static ISP connection. [Connection formats](/guides/proxy-formats).
