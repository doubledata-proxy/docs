---
title: "Manage IP authorization"
description: "Read, set, or remove a subscription's authorized source IP."
---

Each Static ISP subscription can authorize one public IPv4 address.

## Read the current IP

```bash
curl --request GET \
  --url "https://app.proxy.doubledata.com/api/v1/isp/subscriptions/${SUBSCRIPTION_ID}/ip-authorization" \
  --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}"
```

The response contains the authorized address, or `null` if none is set:

```json
{ "ip_authorization": "192.0.2.40" }
```

## Set the IP

<Warning>
  Setting an IP changes live access. Confirm the address before sending.
</Warning>

```bash
export SOURCE_IP="192.0.2.40"

curl --request PUT \
  --url "https://app.proxy.doubledata.com/api/v1/isp/subscriptions/${SUBSCRIPTION_ID}/ip-authorization" \
  --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}" \
  --header "Content-Type: application/json" \
  --data "{\"ip\":\"${SOURCE_IP}\"}"
```

`PUT` creates or replaces the address. Sending the current address succeeds without changes.

## Remove the IP

<Warning>
  Removing the IP may interrupt clients using IP authorization.
</Warning>

```bash
curl --request DELETE \
  --url "https://app.proxy.doubledata.com/api/v1/isp/subscriptions/${SUBSCRIPTION_ID}/ip-authorization" \
  --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}"
```

`DELETE` returns `{"ip_authorization": null}`. Repeating it succeeds when no IP is set.
