---
title: "Order Static ISP proxies"
description: "Quote, order, and manage renewal from your wallet balance."
---

Add funds on the website, then create a quote and confirm it. The API cannot add funds. Confirmation charges your USD wallet before proxy setup starts.

## Check and quote

Check `GET /balance` and `GET /isp/catalog` for tiers, minimum quantities, and countries. Catalog availability is cached; a quote checks live availability and price.

<Warning>
  This quote checks a live production package. It does not charge your wallet. Use it before it expires.
</Warning>

```bash
curl --request POST \
  --url https://app.proxy.doubledata.com/api/v1/isp/quotes \
  --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{
    "tier": "private",
    "countries": [{ "country": "US", "quantity": 5 }],
    "bandwidth_gb": 1000,
    "proxy_replacements": 20,
    "features": [],
    "term": "monthly"
  }'
```

Omit `features` or send `[]` for none. Otherwise, use listed values; never empty strings. The quote checks feature availability and combinations. The server sets prices; omit prices, organization IDs, and idempotency keys.

## Confirm and poll

<Warning>
  Confirmation immediately charges your live wallet. Check the quote and amount before sending.
</Warning>

```bash
export QUOTE_ID="23190741-420c-4f90-839a-33b894ab45a0"

curl --request POST \
  --url https://app.proxy.doubledata.com/api/v1/isp/orders \
  --header "Authorization: Bearer ${DOUBLEDATA_API_KEY}" \
  --header "Content-Type: application/json" \
  --data "{\"quote_id\":\"${QUOTE_ID}\"}"
```

Repeating confirmation for the same quote never charges twice. Success returns `202`, a `Location` status path, and `Retry-After: 2`. Wait at least two seconds, then poll that path:

| Status | Next step |
| --- | --- |
| `processing` | Keep polling. |
| `active` | List proxies using `subscription_id`. |
| `failed_refunded` | Setup failed; the charge was refunded. |
| `failed` | Contact support with the request ID if no refund appears. |
| `outcome_unknown` | Keep polling; do not place a replacement order. |
| `cancelled` | The order stopped before activation. |

## Renewal and cancellation

Keep enough balance for renewal. If payment misses the cutoff, renewal stops and access ends at `current_period_end`.

<Warning>
  `DELETE /isp/subscriptions/{subscriptionId}` stops renewal for a live subscription. Proxies stay available through `current_period_end`. Repeating the request is safe.
</Warning>

Enabled organization admins receive balance and renewal emails for active API-funded ISP subscriptions. Balances below `$5.00` trigger at most one low-balance email every 72 hours per organization.
