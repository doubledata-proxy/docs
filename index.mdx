Use the DoubleData API to check your organization balance, browse ISP availability, create server-priced orders, and manage subscriptions, proxies, rotations, and source-IP authorization.

<Info>
  The API base URL is `https://app.proxy.doubledata.com/api/v1`. Every request uses your organization's API key as a bearer token.
</Info>

## What you can automate

- List active subscriptions with remaining rotation units and reset times.
- Read the USD balance funded through the DoubleData website.
- Browse shared, private, and dedicated availability by country.
- Quote and order recurring Static ISP packages with server-authoritative pricing.
- Cancel renewal while retaining access through the paid period.
- Retrieve complete connection details for each assigned proxy.
- Replace 1–100 selected IPs while preserving each proxy's country.
- Follow asynchronous rotations through terminal results.
- Read, set, or remove the authorized source IP for a subscription.

<Warning>
  The API reference playground sends requests to your live production resources. Read an operation's description before you send a mutation.
</Warning>
