Choose your proxy product in the sidebar. **All proxies** contains shared usage and balance operations. Residential, Datacenter, and Mobile explain each network's connection and targeting parameters. ISP contains catalog, ordering, subscription, rotation, and IP authorization operations.

REST operations include an interactive request builder, response schemas, and examples in cURL, JavaScript, Go, and Python.

| Reference | Use it for |
| --- | --- |
| [All proxies](/api-reference/usage) | Bandwidth, request counts, wallet usage charges, and balance. |
| [Residential](/api-reference/residential) | Residential gateways, location targeting, and sessions. |
| [Datacenter](/api-reference/datacenter) | Datacenter gateways, location targeting, and sessions. |
| [Mobile](/api-reference/mobile) | Mobile gateways, country targeting, and sessions. |
| [ISP](/api-reference/isp) | Static ISP purchasing and subscription management. |

## Base URL

```text
https://app.proxy.doubledata.com/api/v1
```

All requests require `Authorization: Bearer <your_api_key>`.

<Warning>
  The interactive playground calls the production API. `POST`, `PUT`, and `DELETE` requests can change live subscriptions, proxies, or access settings.
</Warning>
